# O.S.A.R. Archive (site do ARG)

Site estático. Os registros em `records/` são criptografados (AES-GCM, chave derivada do código de acesso).
O texto original fica em `tools/arg/records/` no projeto vellum-oru e NUNCA deve ser publicado.

## Publicar
    npx vercel --prod        (dentro desta pasta; na 1ª vez escolha o time e o nome "osar-archive")
